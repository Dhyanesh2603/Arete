# Arete — Personal Operating System for Ambitious Minds

Arete is a Personal Operating System engineered for ambitious individuals who transform identity aspirations (*AI Engineer, Founder, Marathon Runner, Elite Scholar*) into structured, daily mathematical execution.

Built with Flutter Web (Wasm / CanvasKit), Riverpod 2.x, and Supabase (PostgreSQL 16, pgvector, Edge Functions).

---

## The Identity-to-Execution Pipeline

```
[ Target Identity ] -> [ Strategic Goals ] -> [ Weighted Milestones ] -> [ Projects ] -> [ Habits & Tasks ] -> [ Calendar Time-Blocks ] -> [ Telemetry & Analytics ] -> [ AI Cognitive Coach ]
```

---

## System Architecture & Technical Stack

- **Client Runtime**: Flutter 3.x with WebAssembly (Wasm) and CanvasKit compilation.
- **State Management**: Riverpod 2.x (`AsyncNotifier`, code-generation, unidirectional data flow).
- **Persistence Layer**: Offline-first IndexedDB / Hive with background synchronization to Supabase PostgreSQL 16.
- **Semantic Intelligence**: PostgreSQL `pgvector` for semantic search across personal knowledge bases.
- **Routing**: GoRouter 14+ with path URL strategy and global keyboard shortcut interception (`Cmd+K`).
- **Motion & Audio**: Rive 2 state machines, custom GPU canvas painters, and low-latency ambient acoustic soundscapes.
